# GUDDU.exe — Birthday Portfolio

A hacker-style birthday memory website for Guddu, made by Nomesh.

## Folder
- index.html
- style.css
- script.js
- images/
  - 01_guddu_bridal_namaste.jpg
  - 02_guddu_childhood.jpg
  - 03_guddu_nomesh_fun.jpg
  - 04_guddu_childhood_smile.jpg
  - 05_guddu_nomesh_memory.jpg
  - 06_guddu_bava_reception.jpg
  - 07_guddu_bridal_portrait.jpg

## Run
Double-click `index.html` to open it in Chrome/Edge.

For the best result, keep the `images` folder beside `index.html`.

## Customize
- Main birthday message: edit the `message` variable in `script.js`.
- Text and section names: edit `index.html`.
- Colors/visual style: edit the variables at the top of `style.css`.
